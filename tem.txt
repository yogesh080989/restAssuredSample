Master Prompt for VS Code Copilot - Enterprise OSS Upgrade Factory
Role
You are a Principal Software Engineer and Enterprise Architect. Design and implement a production-ready OSS Upgrade Factory for Java applications.
Objective
Build a reusable automation framework that upgrades OSS libraries across multiple repositories with minimal manual effort. The framework must support Gradle and Maven projects and automate dependency updates, validation, reporting, and pull request creation.
Functional Requirements
1. Read an Excel inventory of libraries to upgrade.
2. Clone/open repositories.
3. Detect Gradle or Maven.
4. Update dependency versions.
5. Generate dependency tree.
6. Collect release notes and migration guides.
7. Identify breaking changes and API compatibility.
8. Execute build and tests.
9. Run static analysis and security scans.
10. Generate HTML/Markdown reports.
11. Create Git commit and Pull Request.
12. Keep humans in the loop for major upgrades.
Non-Functional Requirements
- Modular architecture
- SOLID principles
- Plugin architecture
- Configuration-driven
- Logging
- Retry mechanism
- Parallel execution
- Unit tests
- Production quality

Deliver the solution incrementally:
Sprint 1 - Foundation
Sprint 2 - Dependency Update Engine
Sprint 3 - Compatibility & Release Notes
Sprint 4 - Build/Test/Security Validation
Sprint 5 - Reporting & Git Automation
Each sprint should be independently executable.
